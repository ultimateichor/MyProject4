# Setup
- I initialized this Unreal Engine project repository using Git LFS, Github Desktop, and Unreal Engine Revision Control.

1. I created the repository using Github Desktop, using the project's existing file path and matching project name.
2. I then set the necessary .gitignore the same way.
3. With the repository created, I opened my project in Unreal Engine 5 and selected "Revision Control" on the bottom right. The engine recognized the appropriate file path immediately.
4. Finally, I published the repository and pushed the changes.
